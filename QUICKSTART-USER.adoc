= Feedback O Tron — User Quickstart
:toc: preamble

Get up and running in 60 seconds.

== Prerequisites

* Git 2.40+
* just (command runner) — https://just.systems

== Install

[source,bash]
----
git clone https://github.com/hyperpolymath/feedback-o-tron
cd feedback-o-tron
just doctor    # check toolchain
just install   # build feedback-o-tron into ~/.local/bin
----

== First Run

[source,bash]
----
feedback-o-tron --version

# A dry run prints the whole payload and sends nothing
feedback-o-tron submit --repo "test/repo" --title "Test" \
  --body "Test" --platform github --dry-run
----

== Get Help

* `just --list` — every available recipe
* `just doctor` — diagnose toolchain issues
* https://github.com/hyperpolymath/feedback-o-tron/issues — report bugs
